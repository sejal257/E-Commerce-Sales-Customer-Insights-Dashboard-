# E-Commerce-Sales-Customer-Insights-Dashboard-
Interactive E-Commerce Sales Dashboard using Python (Pandas) and Power BI for analyzing sales, profit, and customer insights.
## 📊 Overview
This project focuses on analyzing e-commerce sales data to understand business performance and customer behavior.  
An interactive dashboard was built to explore key metrics like sales, profit, and category performance.

---

## 🛠️ Tools & Technologies
- Python (Pandas)
- Power BI
- Microsoft Excel

---

## 📈 Key Analysis Performed
- Calculated total sales and profit
- Analyzed sales trends over time
- Compared performance across product categories
- Identified top customers contributing to revenue
- Built interactive filters for region-based analysis

---

## 📌 Features of Dashboard
- KPI cards for Total Sales and Total Profit
- Monthly sales trend visualization
- Category-wise sales comparison
- Top customers table
- Region filter (slicer) for dynamic analysis
